Privacy Policy

🔒 The short version

  • No account, no sign-up, no email address required. There is nothing to log into, so we never hold a password or a profile for you.
  • What you paste into a tool stays in your browser. The formatters, encoders, converters, diff, regex and JWT tools are just JavaScript in the page you already downloaded — your input is never sent anywhere. There is exactly one exception, and it is spelled out in §1.
  • We do count visits. Google Analytics 4 is loaded on this site and it sets two cookies. §3 names them and tells you how to opt out.
  • No ads, no ad networks, no retargeting pixels, no session recording, and your data is never sold or shared.

📥 What happens to what you type

Every tool here is a static HTML file with its JavaScript attached. When you open one, your browser downloads the page once and then does all the work locally: JSON parsing and validation, SQL formatting, Base64 encoding, regex matching, hashing, diffing, image conversion. There is no back-end endpoint for your input to be posted to, and the page code contains no request that could carry it off your machine.

The practical consequence: the result is computed on your own device, and it would come out identically if this site went offline the instant after the page loaded.

The one exception is the AI Cover Generator. Generating a cover image needs a model that cannot run inside a browser tab, so that single page POSTs the text you type to our own Cloudflare Pages Function, which relays it to Cloudflare Workers AI (@cf/black-forest-labs/flux-1-schnell). Treat that prompt box as public — do not paste secrets, customer names or anything personal into it. The prompt is used for that one generation; we store neither the prompts nor the generated images.

Downloads — CSV, JSON, PNG, exported HTML — are assembled in your browser as temporary file objects and saved straight to your disk. Nothing is uploaded in order to build them.

🍪 Cookies

This site sets no cookies of its own. There is no cookie banner here because there is nothing of ours to consent to. One third-party script does set cookies, though, and it is only fair to name them:

  • _ga — written by Google Analytics 4. Holds a randomly generated client ID so that repeat visits can be counted as the same browser. Lifetime: up to 2 years.
  • _ga_ESF1YX8CCR — written by Google Analytics 4. Holds session state, such as whether this is a new session and which link brought you here. Lifetime: up to 2 years.

Both are stored for this domain, but the script that creates and reads them belongs to Google. Cloudflare's analytics beacon sends no cookie at all — on a page that loads the Google script, a full visit leaves exactly those two cookies and nothing else.

You can delete or block both at any time from your browser's cookie settings; see §6.

📊 What we measure

The site uses Google Analytics 4 (measurement ID G-ESF1YX8CCR) to see which tools are used and which are not, which is the only reason any of this gets maintained. A standard page view records: the page you opened, the page that referred you, your approximate location (city level, inferred from your IP address), your browser, operating system and device type, and how long the visit lasted.

What it does not contain is anything you typed into a tool, or anything that would let us contact you. We read aggregate reports; we do not attempt to identify individuals.

Cloudflare Web Analytics is also active. Cloudflare injects its beacon (static.cloudflareinsights.com) at its edge, so it is not a tag in our page source and not something we can remove from these files — it is a toggle in the Cloudflare dashboard. It reports aggregated page views and Core Web Vitals and, unlike Google Analytics, sets no cookies and does not follow you to other websites.

That is the complete list. There are no advertising or retargeting pixels, no social network trackers, no heat-map or session-recording scripts, and no affiliate or outbound-click tracking on this site.

We will not claim to honour the legacy Do Not Track header, because Google Analytics 4 ignores it. The opt-out in §6 is the route that actually works.

💾 Local storage (stays on your device)

One tool keeps a convenience cache in your browser, using localStorage rather than a cookie. The SQL Formatter saves your recent queries under the key dt-sql-history, so your history is still there after a reload or a restart.

That data never leaves your browser and nothing is fetched from a server to display it. The page has a Clear button that deletes it, and clearing site data for 23232322.xyz in your browser settings removes it as well. If you are working on a shared machine, clear the history before you walk away.

🌐 Who else sees your request

Loading any web page means your browser makes requests to servers, and those servers can see your IP address and which page asked for the file. These are the only outside parties involved here:

  • Cloudflare Pages (23232322.xyz) — hosts and serves every file on this site and terminates the encrypted connection. Cloudflare processes each request and keeps operational logs (IP address, timestamp, requested URL, user agent) under Cloudflare's privacy policy.
  • Google (googletagmanager.com, google-analytics.com) — serves the analytics script and receives the page views described in §3. See Google's privacy policy.
  • jsDelivr (cdn.jsdelivr.net) — a free public CDN that serves three JavaScript libraries used on two pages: the Markdown renderer and the QR code encoder/decoder. Fetching from it discloses your IP address and the page you are on to that CDN. Their privacy policy is published here.
  • Cloudflare Web Analytics (static.cloudflareinsights.com) — the cookieless beacon described in §3.

Because the site is static there is no application server of ours logging your activity, and no database holding anything about you.

🎛️ Your controls

  • Block the analytics: install Google's own Analytics opt-out browser add-on, or block googletagmanager.com and google-analytics.com with any content blocker. Every tool keeps working — nothing here depends on the analytics script.
  • Delete the cookies: any browser action that clears cookies for 23232322.xyz removes _ga and _ga_ESF1YX8CCR. Blocking third-party cookies alone may not be enough, since these are stored for this domain.
  • Clear the SQL history: use the Clear button on the SQL Formatter page, or clear this site's storage in your browser settings.
  • Turn JavaScript off entirely: that is a complete opt-out of everything described above — it also turns off the tools, which is rather the point of the site.

Writing to hello@23232322.xyz gives us your address and whatever you wrote, and we use it to answer you. There is no newsletter, no mailing list, and your address is not passed to anyone else. Messages are handled by our email provider.

🚫 What we never do

  • Upload the content you paste into a tool — with the single AI Cover Generator exception described in §1.
  • Require an account, take a payment, or store a password.
  • Sell, rent or share personal data with advertisers or data brokers.
  • Run ad networks, retargeting pixels or cross-site tracking.
  • Knowingly collect anything from children. This is a developer utility with no accounts and no personal data, and it is not directed at children.

📝 Changes to this policy

If what the site does changes — a new third-party service, or a new tool that needs a server — this page changes with it and the date below moves. This policy describes the code that is actually deployed, and every claim in it maps to something you can check yourself in your browser's network tab.
