📖 Base64 Encoding & Decoding Explained

Base64 is a binary-to-text encoding that represents arbitrary bytes with 64 printable ASCII characters (A–Z, a–z, 0–9, +, /). It exists because many protocols — MIME email, HTTP headers, JSON, XML, data URIs — can only carry text. Encoding inflates the payload by roughly 33%, which is the trade-off for safe transport.

In practice you meet Base64 in JWT segments, Kubernetes secrets (kubectl get secret), inline CSS fonts, embedded images written as data:image/png;base64,..., and API responses that ship binary payloads as strings. URL-safe Base64 (RFC 4648 §5) swaps + and / for - and _ so the output survives a query string or a filename.

Both directions of this conversion run entirely in your browser — nothing is uploaded, so you can paste credentials, tokens, or customer data without them leaving your machine.
