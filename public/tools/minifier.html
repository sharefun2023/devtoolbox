What This Tool Compresses

  • HTML comments — <!-- ... --> blocks are removed unless they are IE conditional comments.
  • Whitespace between tags — indentation and blank lines collapse away. Spaces that matter between inline elements are kept, so words never run together.
  • CSS & JavaScript — the same page minifies stylesheets and scripts with comment removal and token-aware JS compression.

Content inside <pre>, <textarea>, <script>, and <style> is preserved byte-for-byte, so your rendered layout and embedded logic never break.

Why Minify HTML?

  • Faster page loads — a smaller HTML document means a quicker First Contentful Paint and a better Core Web Vitals score.
  • Lower bandwidth — every visitor downloads less, which matters even more on mobile data plans.
  • Cleaner deployments — hand-written templates ship minified to production while you keep a readable source copy.
